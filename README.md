# Cost Engineering Lab

A collection of focused experiments that investigate how AWS architectures generate cost and how those costs can be explained through engineering analysis.

## Why This Exists

AWS bills are the result of architectural decisions and workload characteristics. This repository investigates the primary cost drivers of AWS services through controlled experiments and validates the resulting engineering analysis against AWS billing.

The objective is to build an engineering intuition for cloud cost analysis that scales from individual services to complete architectures.

## Topics Covered

| **Topic**                      | **Highlights**                                         |
| ------------------------------ | ------------------------------------------------------ |
| **Service Cost Analysis**      | Cost drivers, workload measurement, billing validation |
| **Architecture Cost Analysis** | Cost attribution across multiple AWS services          |
| **Amazon CloudWatch**          | Metrics, logs, operational measurements                |
| **AWS Cost Explorer**          | Cost reporting and billing validation                  |
| **Engineering Methodology**    | Controlled experiments, measurement, findings          |
